# 我的

## 本次范围（2026-10-11）

原文档为空，本次参考 `prototypes/9-我.jpg` 和 `prototypes/10-我-设置-个人资料.jpg`
实现基础个人中心，复用现有登录、收藏、优惠券及购买记录接口。

## 已实现

- 账户卡片：游客登录、当前头像昵称、编辑资料、退出登录。
- 账户概览：我的收藏、可用优惠券、购买记录数量来自服务端；请求失败显示「—」并可重试。
- 常用入口：收藏、领券中心、我的优惠券、购买记录、商品分类、个人资料。
- 浏览足迹：成功访问商品详情后记录，最多 50 条，可查看和清空；展示时重新获取公开商品信息，
  跳过已下架商品。足迹仅在本机保存，并按服务地址隔离。
- 个人资料页：显示账户 ID，通过已有微信资料弹窗修改头像和昵称。
- 商家信息入口仅对后端确认有权限的账户显示；开发连接设置仅在开发版显示。
- 退出登录保留本机购物车；离开页面、切换账户或服务地址后，旧响应和退出确认失效。

## 后端

现有 `GET /api/v1/mini/shop/me` 增加 `favorites_count`、`available_coupon_count`、
`order_count`，按当前客户统计，不受列表分页限制。沿用现有表，无新增表或迁移。
收藏只统计公开可见商品，优惠券只统计已领取且当前有效的券；购买记录包括该客户所有历史记录。
